# Analytic Day 2026 Poster

**Smoking During Pregnancy and Preterm Birth: A Doubly Robust Propensity Score Weighting Analysis of Millions of U.S. Births**

Author: Faruk Muritala. Advisor: Dhrubajyoti Ghosh, Ph.D., Kennesaw State University.

The text, figures and numbers are identical to the C Day 2026 poster. The poster uses the Analytic Day template: Kennesaw State logo with the School of Data Science and Analytics, gold title banner, and plaque section headings. Two layouts are provided.

| File | Layout |
|---|---|
| `Poster_AnalyticDay2026_Muritala_OptionA_Sample_Layout.pptx` / `.pdf` | Text column on the left and a wide figure panel on the right, at the same size as the C Day poster, following the arrangement of the Analytic Day sample poster |
| `Poster_AnalyticDay2026_Muritala_OptionB_Template_Layout.pptx` / `.pdf` | The template's own two-column skeleton, with the figure panel scaled to the right column |

Both carry two QR codes: one for the author's LinkedIn profile and one for this folder.

## Code and data

The numbers come from [`../code/Smoking_Preterm_Full_Analysis.R`](../code/Smoking_Preterm_Full_Analysis.R); the result tables are in [`../results/tables`](../results/tables). What changed since CSOL is in [`../UPDATES_SINCE_CSOL.md`](../UPDATES_SINCE_CSOL.md). The poster contains no trimester results.
